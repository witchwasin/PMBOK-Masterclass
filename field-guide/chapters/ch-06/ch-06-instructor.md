## Teaching Notes

บทนี้ผสาน Quality ฝั่ง Manage Quality (lesson-10 บางส่วน), Resource ฝั่ง Develop/Manage Team (lesson-11 บางส่วน) + Playbook Phase D + Agile inserts (lesson-15/16) — สอนว่า Execution ต้องมีวินัย (DoR/DoD, QA คู่ขนาน, blocker escalation) ไม่ใช่ "เขียน code ให้เสร็จ"

**Cross-reference Quality ครบ 3 จุด:** แผน = Ch.5, QA (กระบวนการ) = Ch.6, QC (ผลจริง) = Ch.8

## Learning Intent

ผู้เรียนต้องสร้าง: DoD compliance decision, blocker/escalation record, conflict resolution approach และเห็นว่า Work Performance Data ถูกเก็บเพื่อ Ch.7

## Thinking Walkthrough

1. DoR ก่อนเริ่ม / DoD ว่าจบ — สองอย่างนี้ต่างกัน
2. QA = กระบวนการ (prevention); QC = ผลจริง (Ch.8)
3. ทีม: Tuckman + conflict resolution 5 เทคนิคเลือกตามสถานการณ์
4. Blocker ต้อง escalate ด้วย evidence + owner
5. Agile: ปกป้อง Sprint Goal; Retro จบด้วย action
6. Work Performance Data เก็บให้ Ch.7
