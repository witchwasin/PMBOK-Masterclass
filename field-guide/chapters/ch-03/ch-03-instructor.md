# Instructor Guide — Chapter 03 (Requirements, Scope และ WBS)

ลิงก์ไป Learner Chapter: [ch-03-learner.md](./ch-03-learner.md)

## Teaching Notes

สอนว่าบทนี้แปลง Stakeholder needs → requirement → scope boundary → WBS ที่ Ch.4 ใช้ต่อได้จริง — เนื้อหาหลักจาก lesson-07 (Scope/WBS เต็มบท) + Playbook C1–C6

**ข้อตีความที่บันทึกไว้:** บทนี้ครอบคลุม C1–C6; ส่วน C7 (Plan Quality and Acceptance / Test Strategy) ถูกเลื่อนไป Ch.5 ตามหลัก "วางแผน Test/Quality → Ch.5, ผลจริง → Ch.8" — ชื่อช่วง C1–C7 ใน Playbook คือช่วง planning ทั้งหมด ไม่ใช่ข้อบังคับให้ C7 อยู่บทนี้ ต้องเขียน cross-reference ชัดเจนทั้ง Ch.3/Ch.5/Ch.8

## Learning Intent

ผู้เรียนต้องสร้าง: Requirements List (testable + traceable), Scope Statement (In/Out), WBS + WBS Dictionary และเข้าใจ Scope Baseline + RTM

## Thinking Walkthrough

1. Stakeholder need → requirement ที่ตรวจรับได้ (อย่าถาม "ทำได้ไหม" ให้ถาม "วัดผลยังไง")
2. SRS/FSD ตัดสินด้วย coverage ไม่ใช่ชื่อไฟล์
3. Product vs Project scope แยกให้ชัด
4. WBS แตกตาม deliverable ผ่าน 100% Rule
5. WBS Dictionary = ข้อมูลที่ WBS diagram บอกไม่ได้
6. Scope Baseline ต้อง approval ก่อน build
7. Cross-ref: Test Strategy = Ch.5, Test Results = Ch.8

## Scenario Note

ตั้งแต่ Ch.3 กลับมาใช้ทีม SHG ภายใน (คุณสุทธิ PM, คุณนภา PO) ตาม Scenario Master — ตัวเลข In/Out of Scope ตรง Scenario Master §4 (loyalty, digital key, chatbot = Out of Scope)
