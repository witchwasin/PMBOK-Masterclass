# Instructor Guide — Chapter 10 (Transition & Closure)

ลิงก์ไป Learner Chapter: [ch-10-learner.md](./ch-10-learner.md)

## Teaching Notes

บทนี้คือ Integration ท่อนที่ 3 (Close Project or Phase — lesson-05 บางส่วน) + Playbook Phase H — **ต้องชี้ชัด Integration ครบ 3 ท่อน: Charter = Ch.2, Change Control = Ch.7, Closure = บทนี้** — และเชื่อมบทเรียน lesson-01: Output ≠ Outcome ≠ Benefit; Go-live ≠ Closure

## Learning Intent

ผู้เรียนต้องสร้าง: Closure recommendation + open-items log, handover checklist, lessons register (พร้อม action owner), benefit handover plan

## Suggested Timing

| Segment | Time (นาที) |
|---|---:|
| Opening + Why | 10 |
| Handover + Acceptance (H.3–H.4) | 20 |
| Contract + Lessons (H.5–H.6) | 15 |
| Benefit Handover + Report (H.7–H.8) | 20 |
| Workshop | 25 |

## Thinking Walkthrough

1. Handover = owner + support model + SLA + runbook + known issues
2. Acceptance อ้าง evidence (Ch.8) ไม่ใช่ "ดูแล้วโอเค"
3. ปิด contract/finance ให้ครบ
4. Lessons ต้องมี action owner
5. Benefit Owner = business (คุณภัทร); PM ตั้ง ownership ให้ชัดก่อนจาก
6. Exit criteria (H.9) ครบ → Sponsor อนุมัติ → PIR
