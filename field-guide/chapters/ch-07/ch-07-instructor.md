## Teaching Notes

บทนี้ผสาน Perform Integrated Change Control (lesson-05), Cost Control/EVM (lesson-09 บางส่วน), Control Schedule (lesson-08 บางส่วน) + Playbook Phase E — **นี่คือ Integration ท่อนที่ 2** (Charter = Ch.2, Change = บทนี้, Closure = Ch.10) ต้องชี้ให้เห็นเส้นนี้ชัด

ผู้เรียนต้องสร้าง: impact pack (ครบทุกด้าน), CCB recommendation (options + authority), recovery brief และรู้จัก monitoring cycle + escalation conditions

## Thinking Walkthrough

1. Collect -> compare -> variance -> cause -> options -> decide -> verify
2. EVM <1 = ประตูคำถาม ไม่ใช่คำตอบ
3. Change: intake -> impact ครบด้าน -> authority -> baseline update -> verify
4. Issue ≠ Change Request — แยก log
5. Escalate ตามเงื่อนไข E.10; RAID review ต่อเนื่อง
6. ทุก decision มี record + communication

## Scenario Note

ตัวเลข EVM ตัวอย่าง (PV 7.5 / EV 6.75 / AC 7.5 → SPI/CPI 0.90, EAC ≈ 13.3M, VAC ≈ -1.3M) เป็น Teaching Scenario — อย่าขัดกับ budget context 12M (Contingency 1.5M, Management Reserve 1.5M) ของ Scenario Master
