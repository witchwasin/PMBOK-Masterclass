## Thinking Walkthrough

1. WP -> Activity -> Dependency -> Duration -> CPM -> Baseline
2. Delay: ดู critical path + float ก่อนเสนอ recovery (มี mechanism)
3. EVM: อ่าน EV คู่กับ evidence; ตัวเลข <1 เป็นประตูคำถามไม่ใช่คำตอบ
4. Reserve: contingency (PM ตาม governance) vs management (Sponsor)
5. Resource: capacity sign-off จาก functional manager; RACI A หนึ่งคน
6. Agile: Scrum = increment, Kanban = flow, Hybrid = control + sprint

## Scenario Note

ตัวเลขตาม Scenario Master: 12M budget breakdown (Contingency 1.5M, Management Reserve 1.5M), Sprint 0–12, 80 key users, launch ก่อน 1 พ.ย.
