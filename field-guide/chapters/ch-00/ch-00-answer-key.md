# Answer Key — Chapter 00 (PMBOK Primer)

Instructor-facing only.

## หมายเหตุ

บทปฐมบท (Ch.0) ไม่มี Workshop และ Assessment โดยการออกแบบ — ไฟล์นี้ให้แนวทาง (model guidance) สำหรับ discussion prompts ใน instructor guide และคำถามท้ายบท (Checkpoint ผ่านบทถัดไป)

## Discussion Prompt 1 — PMBOK ต่างจาก methodology อย่างไร

**แนวตอบ:** PMBOK คือ Body of Knowledge (คลังความรู้/แผนที่ของคำถามสำคัญ) — ไม่มีขั้นตอนตายตัว, ไม่ได้เลือก Waterfall/Agile ให้, ไม่รับประกันความสำเร็จ — Methodology (เช่น Scrum, Waterfall) คือชุดวิธีทำงานที่เจาะจง — PMBOK ช่วยให้รู้ว่าต้องถามอะไร; methodology ตอบว่าทำยังไงในบริบทนั้น

## Discussion Prompt 2 — Study Mode vs Field Mode

**แนวตอบ:** Study Mode = อ่านเรียง Ch.0–10 เพื่อสร้างฐานครบ (เหมาะ PM ใหม่/โครงการแรก) — Field Mode = เปิดบทที่ตรงกับปัญหา + Quick Reference Card + Appendix (เหมาะ PM มีประสบการณ์/งานเร่ง) — เกณฑ์เลือก: ประสบการณ์, ความเร่งด่วน, ความเสี่ยงของงาน

## Discussion Prompt 3 — Process Group ต่างจาก Phase อย่างไร

**แนวตอบ:** Process Group (Initiating→Closing) คือกลุ่มกิจกรรมบริหารที่เกิดซ้ำได้ตลอดโครงการ (วางแผน-ทำ-ควบคุม วนต่อเนื่อง) — Phase/A–H คือช่วงเวลาจริงที่งานเดิน (Pre-sales → Closure) — สับสนสองอย่างนี้ทำให้คิดว่าวางแผนครั้งเดียวแล้วจบ

## เกณฑ์ประเมิน (สำหรับบทถัดไป)

ผู้เรียนพร้อมเดินต่อเมื่อ: อธิบาย PMBOK ≠ methodology ได้, บอกโครง A–H ได้, รู้จัก Scenario SHG (12M, 35%/18 เดือน, launch ก่อน 1 พ.ย.), และเลือกโหมดอ่านได้อย่างมีเหตุผล
